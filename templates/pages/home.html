UI components for Django. Copy, own, customize. Inspired by shadcn/ui.

Browse components GitHub

Installation

1. Install SilkUI:

pip install silkui

2. Add to INSTALLED_APPS:

INSTALLED_APPS = [
    ...
    "silkui",
]

3. Load and use in your templates:

{% verbatim %}{% load silkui_tags %}
{% button %}Click me{% endbutton %}{% endverbatim %}
