HTMX Integration

SilkUI components accept any hx_* prop, which is automatically converted to an hx-* HTML attribute.

How it works: write hx_post="/url/" → SilkUI outputs hx-post="/url/". Same for all HTMX attributes: hx_get, hx_target, hx_swap, hx_trigger, etc.

Setup

Add HTMX to your base template:

<script src="https://unpkg.com/htmx.org@2.0.0"></script>

Button — POST request

A button that sends a POST and swaps a target element with the response.

{% verbatim %}{% load silkui_tags %}

{% button hx_post="/tasks/42/complete/" hx_target="#task-42" hx_swap="outerHTML" %}
  Mark as done
{% endbutton %}{% endverbatim %}
# views.py
def complete_task(request, task_id):
    task = Task.objects.get(pk=task_id)
    task.done = True
    task.save()
    return render(request, "partials/task_row.html", {"task": task})

Live Search Input

Input that triggers a GET on every keystroke with a 300ms debounce.

{% verbatim %}{% load silkui_tags %}

{% input name="q"
         label="Search users"
         placeholder="Type to search..."
         icon="🔍"
         icon_position="left"
         hx_get="/users/search/"
         hx_target="#results"
         hx_swap="innerHTML"
         hx_trigger="keyup changed delay:300ms" %}

<div id="results">
  {% for user in users %}
    <p>{{ user.name }}</p>
  {% endfor %}
</div>{% endverbatim %}
# views.py
def search_users(request):
    q = request.GET.get("q", "")
    users = User.objects.filter(name__icontains=q)
    return render(request, "partials/user_list.html", {"users": users})

Form — submit without page reload

Full form that submits via HTMX and swaps the success message in place.

{% verbatim %}{% load silkui_tags %}

<form hx-post="/contact/" hx-target="#contact-form" hx-swap="outerHTML" id="contact-form">
  {% csrf_token %}
  {% input name="name" label="Name" required=True %}
  {% input name="email" label="Email" type="email" required=True %}
  {% textarea name="message" label="Message" rows=4 required=True %}
  {% button type="submit" hx_indicator="#spinner" %}Send message{% endbutton %}
  <span id="spinner" class="htmx-indicator text-sm text-muted-foreground ml-2">Sending...</span>
</form>{% endverbatim %}
# views.py
def contact(request):
    if request.method == "POST":
        # process form...
        return render(request, "partials/contact_success.html")
    return render(request, "contact.html")

Dependent Select (cascading)

When the user changes a select, HTMX loads the options for the next select dynamically.

{% verbatim %}{% load silkui_tags %}

{% select name="country"
          label="Country"
          choices=country_choices
          placeholder="Select country..."
          hx_get="/cities/"
          hx_target="#city-select"
          hx_trigger="change"
          hx_include="[name='country']" %}

<div id="city-select">
  {% select name="city" label="City" choices=city_choices placeholder="Select city..." %}
</div>{% endverbatim %}
# views.py
def cities(request):
    country = request.GET.get("country")
    cities = City.objects.filter(country=country).values_list("id", "name")
    return render(request, "partials/city_select.html", {"city_choices": list(cities)})

Delete with confirmation modal

Open a confirm modal, then trigger HTMX DELETE on confirm.

{% verbatim %}{% load silkui_tags %}

{% modal id="del-{{ item.id }}" trigger_label="Delete" title="Delete this item?" description="This cannot be undone." %}
  <div class="mt-4 flex justify-end gap-2">
    {% button variant="outline" %}Cancel{% endbutton %}
    {% button variant="destructive"
              hx_delete="/items/{{ item.id }}/"
              hx_target="#item-{{ item.id }}"
              hx_swap="outerHTML swap:0.3s"
              hx_confirm="Are you absolutely sure?" %}
      Delete
    {% endbutton %}
  </div>
{% endmodal %}{% endverbatim %}

Inline edit

Click a value to edit it in place, save with HTMX PATCH.

{% verbatim %}{% load silkui_tags %}

<div id="user-name" x-data="{ editing: false }">
  <span x-show="!editing" @click="editing = true" class="cursor-pointer hover:underline">
    {{ user.name }}
  </span>
  <div x-show="editing" class="flex gap-2">
    {% input name="name"
              value=user.name
              hx_patch="/users/{{ user.id }}/"
              hx_target="#user-name"
              hx_swap="outerHTML"
              hx_trigger="keyup[key=='Enter']" %}
    <span class="text-xs text-muted-foreground mt-2">Press Enter to save</span>
  </div>
</div>{% endverbatim %}

HTMX props reference

All hx_* and data_* props auto-convert to their HTML attribute equivalent.

Prop (Django) HTML output Description
hx_get="/url/"hx-get="/url/"GET request on trigger
hx_post="/url/"hx-post="/url/"POST request on trigger
hx_patch="/url/"hx-patch="/url/"PATCH request
hx_delete="/url/"hx-delete="/url/"DELETE request
hx_target="#id"hx-target="#id"Element to swap
hx_swap="outerHTML"hx-swap="outerHTML"How to insert response
hx_trigger="keyup"hx-trigger="keyup"Event that fires the request
hx_indicator="#id"hx-indicator="#id"Loading indicator element
hx_confirm="Sure?"hx-confirm="Sure?"Native confirm dialog before request
hx_push_url="true"hx-push-url="true"Updates browser URL
